# 📑 Phase 4 작업 지시서: AI 및 미디어 자동화 안정화

본 지시서는 프로젝트의 핵심 차별점인 AI 기반 자동화 기능을 견고하게 만들기 위한 작업 단계를 정의합니다.

## 1. 미디어 EXIF 자동화 정교화
### 1.1 여행 일자(Day) 계산 로직 보강
- **대상**: `inferDay` 함수 (`server/routes.ts`)
- **작업 내용**: 
    - 사진 촬영지 정보(GPS)와 타임라인 시작 위치의 타임존 차이를 고려한 날짜 보정 로직 추가.
    - 사진 데이터 오염 시 수동 입력 날짜를 최우선으로 적용하는 우선순위 체계 확립.
- **의도 보존**: 사용자가 사진만 올려도 여행기가 자동으로 구성되는 UX 유지.

### 1.2 트랜잭션 안전성 강화
- **작업 내용**: 
    - 파일 업로드 -> EXIF 파싱 -> DB 기록 단계에서 에러 발생 시 GCS에 업로드된 잔여 파일 정리 로직 보강.

## 2. AI 사용량 및 품질 관리
### 2.1 사용량 쿼터 미들웨어 구현
- **대상**: `middleware/checkAiUsage.ts`
- **작업 내용**: 
    - OpenAI/Anthropic API 호출 전 사용자의 일일 사용량을 체크하여 비용 폭증 방지.
    - 관리자가 `system_config` 테이블을 통해 실시간으로 한도를 조절할 수 있도록 연동.
- **주의**: 기능을 막는 것이 아니라, 정상적인 서비스 운영을 위한 안전장치 마련.

### 2.2 AI 프롬프트 템플릿 관리 강화
- **작업 내용**: 
    - AI 프롬프트 수정 시 이전 버전을 보관(Versioning)하는 기능 추가.
    - 템플릿 내의 변수 치환 로직 유효성 검사 강화.

## 3. 프론트엔드 마무리 및 최적화
- **작업 내용**: 
    - `App.tsx`의 직접적인 `window.location.href` 사용을 Wouter의 `useLocation` 또는 `Redirect`로 전환하여 SPA 아키텍처 준수.
    - 주요 페이지의 메타 태그(SEO) 자동 생성 로직 점검.
